# CodeAlpha Task 1 – Simple E-commerce Store 🛒

This project is developed as part of the **CodeAlpha Full Stack Development Internship – Task 1**.

## 📌 Project Description
A simple E-commerce web application built using Django where users can:
- Browse products
- View product details
- Add items to cart
- Place orders
- Register and login users

## 🛠️ Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite Database

## ✨ Features
- Product listing
- Product details page
- Shopping cart
- Order processing
- User authentication (Login/Register)
- Admin panel for managing products and orders

## ▶️ How to Run the Project
1. Clone the repository
2. Create and activate a virtual environment
3. Install dependencies
4. Run the server:
```bash
python manage.py runserver
